# Profile Card Component - Frontend Mentor Challenge
This is my solution to the **Profile Card Component** challenge from Frontend Mentor.  
The project is built using **HTML and CSS**, with a focus on responsive design, clean UI, and layout structure.

## Features
- Fully responsive layout (mobile + desktop)
- Clean profile card design with overlapping profile image
- Centered layout using Flexbox
- Background pattern styling
---
## What I Learned
- How to layout a card component using Flexbox instead of relying on absolute positioning
- How to overlap an image over a background using negative margins
- Why hardcoded `vw`/`vh` values make layouts fragile, and using `max-width` instead
- How to structure a real-world UI from a given design
---
## Challenges Faced
- Fixing conflicts between `position: absolute` and Flexbox layout
- Getting the profile picture to overlap the top background correctly
- Making the card size responsive instead of relying on viewport units
---
